プライバシーポリシー

最終更新日: 2026年11月3日

本プライバシーポリシーは、個人開発のアプリケーション「RUBICON」(以下「本アプリ」)における、 利用者の情報の取り扱いについて説明するものです。

1. 基本方針

保存した記事、ハイライト、メモ、判断基準、プロフィール、対話の履歴は、利用者の端末内に保存されます。 開発者のサーバーには保存しません。

ただし、AI の機能(デイリー・ブリーフと執事との対話)を使うときに限り、その応答を作るために必要な内容を、 開発者のサーバーを経由して Anthropic 社に送ります(第3条)。AI の機能は、アプリ内で同意をいただいてから使えるようになります。

2. 端末内にのみ保存される情報

  • 保存した記事の本文・URL・タグ・既読やアーカイブなどの状態
  • ハイライトとメモ
  • 判断基準、プロフィール、呼び方
  • デイリー・ブリーフと対話の履歴
  • アプリの表示設定

記事を保存すると、題名や画像などを取得するために、端末から記事のサイトに直接アクセスします。 このとき開発者のサーバーは経由しません。 他のアプリからの共有(共有シート)で受け取った URL やテキストは、端末内で本アプリに受け渡されるだけです。

3. AI の機能を使うときに送る情報

デイリー・ブリーフを作るときと、対話を送るときだけ、次の内容を送ります。記事を保存したり読んだりするだけでは送りません。

  • 保存した記事の題名・サイト名・要旨と、本文の抜粋
  • ハイライトとメモ
  • 判断基準・プロフィール・呼び方
  • 対話でのご発言と、それまでのやり取り
  • 利用状況の統計(判断基準の件数など。中身は含みません)

これらは開発者のサーバーを経由して Anthropic 社(米国)の API に送られ、応答の作成に使われます。 開発者のサーバーは、送られた内容を保存しません。 Anthropic 社は、API で受け取った内容をモデルの学習に使いません。 Anthropic 社での取り扱いは、Anthropic 社のプライバシーポリシーに従います。

同意は、アプリの設定の「AI への送信」からいつでも取り消せます。 同意されない場合も、記事の保存・閲覧・ハイライト・検索・書き出しはご利用いただけます。

4. 開発者のサーバーに記録する情報

本アプリには、氏名・メールアドレス・電話番号などを登録する仕組みはありません。 本アプリが初めて開発者のサーバーにつながるとき(購読の状態の確認や AI の機能を使うとき)、利用者ごとに無作為な識別子(以下「利用者 ID」)が自動で作られます。 開発者のサーバーには、この利用者 ID に結びつけて、次の情報だけを記録します。

情報目的
AI の利用量(機能の種類、文字数の目安、費用、日時) 無料体験と有料プランの利用上限の管理、費用の把握
利用状況の統計(判断基準の件数。中身は含みません) 本アプリの改善(機能がどの程度使われているかの集計)
無料体験の開始日時と、その端末で体験を使用済みかどうかの判定結果 無料体験の管理、体験の繰り返し利用の防止
購読の状態(プラン、請求期間、有効期限)と、購入に関する通知の受信記録 有料プランの提供

記事・ハイライト・判断基準・対話の内容は、ここに含まれません。 集計の結果を、個人を特定できない形で本アプリの改善に使うことがあります。

5. 利用する外部のサービス

本アプリは、次の外部のサービスを利用します。各社での情報の取り扱いは、各社のプライバシーポリシーに従います。

サービス用途と、渡る情報
Anthropic(米国) AI の応答の作成。第3条の内容
プライバシーポリシー
Supabase(サーバーは日本・東京) 開発者のサーバー(データベースと、AI への中継)。第4条の情報
プライバシーポリシー
RevenueCat(米国) 購読の管理。利用者 ID、App Store での購入の記録、端末の種類や OS の版などの技術的な情報。記事や判断基準は渡りません
プライバシーポリシー
Firebase App Check(Google、米国) 開発者のサーバーへの通信が、正規のアプリと端末からのものかの確認。Apple の App Attest による確認の情報
プライバシーポリシー
Apple DeviceCheck 無料体験を、その端末ですでに使ったかどうかの確認。Apple が端末ごとに保持する2つの値だけを使い、端末を識別する情報を開発者が保存することはありません
プライバシーポリシー

これらのサービスとの通信では、各社のサーバーが IP アドレスなどの通信の情報を受け取ることがあります。

本アプリは、次のものを利用しません。

  • 広告と、広告識別子(IDFA)などのトラッキング
  • アクセス解析のサービス
  • クラッシュレポートの外部送信

6. 第三者への提供

開発者は、法令に基づく場合を除き、利用者の情報を第三者に提供しません。 第3条・第5条による外部のサービスへの送信は、本アプリの機能を提供するための委託として行います。

7. 情報の管理と削除

端末内のデータは、アプリの設定から書き出し(バックアップ)や、すべての削除ができます。 アプリを削除すると、端末内のデータも削除されます。

開発者のサーバーの記録(第4条)は、最後に AI の機能を使った日と、購読や無料体験の記録が最後に更新された日のうち、遅いほうから2年が過ぎると、自動で削除します。 アプリの設定の「サーバーの記録を削除」から、いつでもご自身で削除することもできます。 このとき、RevenueCat にある購読の管理の記録も削除を依頼します。 購読そのものは解約されません。解約は、iPhone の「設定」→ ご自身の名前 →「サブスクリプション」から行えます。

アプリを削除すると、端末にあった利用者 ID も失われるため、開発者はその記録がどなたのものかを特定できなくなります。 その記録は、上記の2年が過ぎた時点で削除されます。

8. 対象年齢

本アプリは、成人の利用者を主な対象としています。未成年の方が有料プランを購入される場合は、保護者の同意を得てください。

9. 本ポリシーの変更

本ポリシーは、本アプリの機能の変更に伴い更新することがあります。 AI に送る内容や送り先を変える場合は、アプリ内であらためて同意をお願いします。
