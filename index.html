プライバシーポリシー

最終更新日: 2026年8月14日

本プライバシーポリシーは、個人開発アプリケーション「Rubicon」（以下「本アプリ」）における、 利用者の情報の取り扱いについて説明するものです。

1. 基本方針

本アプリは「ローカルファースト」の設計思想に基づいており、利用者が保存した記事、ハイライト、 メモ、対話履歴などのデータは、開発者が運営するサーバーには送信・保存されません。 すべてのデータは利用者ご自身の端末内に保存されます。

2. 収集する情報とその取り扱い

2.1 端末内にのみ保存される情報

以下の情報は、利用者の端末内のデータベースにのみ保存され、外部に送信されることはありません。

  • 保存した記事の本文・URL・タグ・既読状態・アーカイブ状態・スター状態
  • 記事に対するハイライトおよび引用箇所、メモ
  • AI機能によって生成された要約・分析（ブリーフ）およびその対話履歴
  • 利用者が入力するプロファイル情報（自己紹介・関心領域など）
  • アプリの表示設定（フォント、配色、表示モードなど）

2.2 Anthropic API キー（BYOK）

本アプリは「Bring Your Own Key（BYOK）」方式を採用しています。利用者は、AI機能（記事の分析、 ブリーフ生成、対話機能）を利用するために、ご自身の Anthropic API キーをアプリ内に設定する 必要があります。

  • API キーは端末内に安全に保存され、開発者のサーバーに送信されることはありません。
  • AI機能利用時、関連するデータ（記事の要旨、ハイライト、プロファイル情報等）は、 利用者自身の API キーを用いて、利用者の端末から Anthropic 社の API に直接送信されます。 この通信は開発者を経由しません。
  • 送信されたデータの取り扱いについては、 Anthropic社のプライバシーポリシー が適用されます。

2.3 共有機能

他のアプリ（Safari、X など）から記事を共有保存する機能（iOS Share Extension）は、 共有された URL やテキストを端末内のアプリ間でのみ受け渡します。この情報が外部に送信されることはありません。

2.4 開発者が収集しない情報

本アプリは、以下の情報を収集・保存する仕組みを実装していません。

  • アクセス解析・アナリティクス
  • クラッシュレポート・エラーログの外部送信
  • 広告識別子・トラッキング用データ
  • 氏名・メールアドレス・電話番号等の登録情報（アカウント登録機能自体が存在しません）

3. データの管理・削除

利用者は、アプリ内の設定画面から、保存されたすべてのデータをエクスポート（バックアップ）または 完全に削除することができます。アプリをアンインストールした場合、端末内に保存されていたデータは 端末の仕様に基づき削除されます。

4. 第三者への提供

開発者は、利用者の同意なく、本アプリで扱う情報を第三者に提供することはありません。 AI機能利用時に Anthropic 社へ送信される情報は、利用者ご自身の判断と設定（API キー）に基づくものであり、 開発者がこれを閲覧・収集することはありません。

5. 対象年齢

本アプリは個人の情報整理・分析を目的としたツールであり、成人利用者を主な対象としています。

6. 本ポリシーの変更

本ポリシーの内容は、本アプリの機能変更に伴い更新されることがあります。重要な変更がある場合は、 本ページ上で告知します。

お問い合わせ
本ポリシーに関するご質問は、アプリ内の設定画面からご連絡ください。
